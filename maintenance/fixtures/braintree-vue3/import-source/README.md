# braintree-vue3

Vue 3 composables wrapping the [Braintree Web SDK](https://github.com/braintree/braintree-web).

## Installation

```sh
npm install braintree-vue3 braintree-web vue
```

## Usage

```typescript
import { useBraintreeClient, useHostedFields } from 'braintree-vue3'
```

See the source for full API details.
